🚀 Power BI Project: Airport Operations Dashboard (Departures & Arrivals)

I recently developed an end-to-end Power BI solution to monitor and analyse airport traffic operations across South African airports. These dashboards will aid our simulation team by enabling faster working process by eliminating the process of data collection, cleaning, transformation for simulations.

📊 Project Overview

* Built two interactive dashboards: Departures (`Departures.jfif`) and Arrivals (`arrivals.png`)
* Data sourced from tower logs (2021 – March 2026) via DirectQuery
* Directly imported airports information created on Transoft AirTOP simulation software.

🛠 Data Engineering & Modeling

* Cleaned and transformed data using Power Query
* Created a custom date table
* Designed a structured data model with relationships for the 3 tables

Developed DAX measures to track:

* Total flights
* Average taxi time
* Peak congestion periods vs low-traffic windows
* Calculated take-off time compliance
* Flight routes usage

📈 Key Insights & Visuals

* Hourly & daily movement trends
* Wake Turbulence Category (WTC) distribution across airports
* Busiest routes by volume
* Detailed flight-log table (exportable for airspace and airports simulations)
* Calculated take-off time compliance
